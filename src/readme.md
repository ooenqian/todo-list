**Run the Application**
1. Download or clone the project repository to your computer.
2. Open the project folder in Visual Studio Code or another code editor.
3. Locate the src folder.
4. Open index.html in a web browser.

**How to Use the Application**
1. Click the Add Task button to open the task form.
2. Enter the task title and, optionally, a description.
3. Select a priority level.
4. Click Add Task to create the task.
5. Click the tick button to mark a task as completed or pending.
6. Click Edit to modify an existing task.
7. Click Delete to remove a task.
8. Use the filter options to display all, pending, or completed tasks.

**Data Storage and Limitations**
Tasks are stored temporarily in a JavaScript array while the application is running. The application does not currently use a database or browser storage to save tasks permanently. Therefore, tasks will be lost when the page is refreshed or closed.
